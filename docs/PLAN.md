### Phase 1 — Seed data & normalization (≤ 2h)

      areaM2, rooms, floor, buildingAge, elevator, parking, storage, description, postedAt, imageUrl?

### Phase 2 — Intent parsing (≤ 3h)
- [x] `SearchIntent` schema (zod): maxDeposit, maxRent, flexibleConversion, neighborhoods[],

- [x] Provider abstraction `lib/ai/` with `mock` and one OpenAI-compatible client (base URL + key + model per provider: `gemini` default,

- [x] `POST /api/search` → returns `{ intent, results }`
- [x] 8–10 sample queries in `lib/demo-queries.ts` used for manual testing and the UI

### Phase 3 — Ranking & explanations (≤ 3h)
- [x] Hard filter on budget (using normalization when `flexibleConversion`) — done in Phase 2
- [x] Soft score: neighborhood match, rooms, area, amenities, recency; weights in one config
- [x] One batched LLM call for top ~10 results → 1–2 sentence Persian explanation each,

- [x] Graceful fallback: if LLM fails, show rule-based explanation
